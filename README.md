# mon-projet-python

Même script interactif que l'exercice 2 (chat, image, vidéo), mais écrit avec le SDK Python `rodiumai`.

## Installation

Python 3.11

```
pip install -r requirements.txt
```

## Configuration

```
cp .env.example .env
```

Puis mettez votre clé dans le fichier `.env`.

## Lancer

```
python main.py
```
